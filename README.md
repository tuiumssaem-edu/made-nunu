# 다람쥐의 과자 나라 모험 🐿️🍭

아이가 직접 그린 그림을 바탕으로 만든 웹 게임입니다.
컴퓨터, 태블릿, 휴대폰 어디서든 브라우저로 바로 플레이할 수 있습니다.

## 게임 소개
- **과자 마을**: 롤리팝 기둥과 환영 가랜드가 있는 입구를 지나면 광장의 초콜릿 분수가 나오고, 분수 뒤에는 과자 상점이 있습니다.
- **체육관 4곳**: 불꽃 · 물방울 · 번개 체육관에서 몬스터 3마리와 차례로 싸워 배지를 모읍니다. 배지 3개를 모으면 과자왕 체육관이 열립니다.
- **금화와 상점**: 몬스터를 이기면 금화를 받고, 상점에서 회복 과자(쿠키·케이크)를 사거나 기술을 업그레이드합니다.
- 몬스터를 물리쳐도 체력이 자동으로 회복되지 않으니 회복 과자를 잘 챙기세요.

## 조작 방법
| | 휴대폰·태블릿 | 컴퓨터 |
|---|---|---|
| 이동 | 화면 아래 방향 버튼, 또는 화면을 꾹 누르기 | 방향키 / WASD |
| 공격 | 🌰 도토리 미사일, ✨ 별빛 스매시 버튼 | Z / X |
| 회복 | 🍪 쿠키, 🍰 케이크 버튼 | C / V |

## 실행 방법
`index.html` 파일을 브라우저로 열면 바로 실행됩니다.
진행 상황(금화·배지·아이템)은 플레이한 기기의 브라우저에 저장됩니다.
